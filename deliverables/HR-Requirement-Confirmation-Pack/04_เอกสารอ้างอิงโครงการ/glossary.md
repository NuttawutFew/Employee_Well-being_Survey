# คำศัพท์ของระบบประเมินสุขภาพใจ

เอกสารนี้ปรับปรุงระหว่างการเก็บความต้องการ รายการที่ยังไม่ได้ข้อสรุปจะระบุว่า “รอตัดสินใจ”

## ผู้ทำแบบประเมิน

พนักงานขององค์กรที่ผ่านการยืนยันตัวตนด้วย SSO และทำแบบประเมินสุขภาพใจด้วยตนเอง

## Single Sign-On (SSO)

กลไกยืนยันตัวตนผ่านระบบบัญชี OnePlatform ขององค์กร เมื่อเข้าสู่ระบบสำเร็จ ระบบประเมินจะได้รับตัวระบุที่เชื่อถือได้และใช้ดึงข้อมูลพนักงาน โดย protocol และ contract การเชื่อมต่อยังรอตัดสินใจ

## ข้อมูลพนักงาน

ข้อมูลจาก OnePlatform ที่นำมาเชื่อมกับรอบการประเมิน ได้แก่ รหัสพนักงาน ชื่อ นามสกุล เพศ อายุ เบอร์โทร บริษัท แผนก ตำแหน่ง พื้นที่ปฏิบัติงาน และข้อมูลที่ใช้คำนวณอายุงาน ระบบใช้รหัสพนักงานเชื่อมประวัติ ส่วนข้อมูลอื่นใช้เพื่อแสดงผลและการบริหารจัดการ

## Employee Snapshot

สำเนาข้อมูลพนักงานจาก OnePlatform ณ เวลาส่งแบบประเมิน ใช้แสดงและคำนวณรายงานย้อนหลังเพื่อไม่ให้ผลเปลี่ยนเมื่อข้อมูลต้นทางเปลี่ยนภายหลัง

## การประเมินด้วยตนเอง

ผู้ทำแบบประเมินเป็นผู้เลือกคำตอบ อ่านผล และตัดสินใจดำเนินการต่อด้วยตนเอง ระบบไม่มีเจ้าหน้าที่ติดตามผลแบบเรียลไทม์

## การคัดกรอง

การประเมินเบื้องต้นด้วยแบบวัดมาตรฐาน ผลลัพธ์ไม่ใช่การวินิจฉัยโรคหรือคำแนะนำทางการแพทย์เฉพาะบุคคล

## ชุดแบบประเมิน

- ภาวะหมดไฟในการทำงาน (Burnout): 22 ข้อ
- ความเครียด (Stress Test): 20 ข้อ
- พลังสุขภาพจิต (RQ): 20 ข้อ
- ความเสี่ยงโรคซึมเศร้า (9Q): 9 ข้อ
- ความเสี่ยงซึมเศร้าและฆ่าตัวตาย (2Q Plus): 3 ข้อ

## เหตุการณ์ความเสี่ยงเร่งด่วน

ผลตอบที่บ่งชี้ความเสี่ยงต่อการฆ่าตัวตายหรือการทำร้ายตนเอง ซึ่งต้องเปลี่ยนเส้นทางผู้ใช้ไปยังคำแนะนำเพื่อขอความช่วยเหลือทันที รายละเอียดเกณฑ์และวิธีตอบสนองรอตัดสินใจ

## รอบการประเมิน

การทำแบบประเมินทั้ง 5 ชุดตามลำดับตายตัวให้ครบหนึ่งครั้ง ก่อนเข้าสู่หน้าสรุปผลรวม พนักงานหนึ่งคนส่งรอบการประเมินได้เพียงหนึ่งครั้ง

## Draft

รอบการประเมินที่ยังไม่ได้ส่ง ระบบบันทึกคำตอบอัตโนมัติและพนักงานสามารถกลับมาทำต่อจากจุดเดิม หรือล้างคำตอบทั้งหมดเพื่อเริ่มใหม่ได้

## Submitted

รอบการประเมินที่ส่งครบทั้ง 5 ชุดแล้ว ระบบคำนวณและเปิดหน้าสรุปผล และนับเป็นการใช้สิทธิ์ทำแบบประเมินหนึ่งครั้งของพนักงาน

## Admin Reset

การที่ Admin เปิดสิทธิ์ให้พนักงานซึ่งเคยส่งสำเร็จแล้วกลับมาทำแบบประเมินใหม่ได้ ต้องมี audit log ระบุผู้ดำเนินการ เวลา และเหตุผล ผลเดิมถูกเก็บเป็นประวัติในสถานะ Cancelled และไม่นำไปคำนวณ dashboard

## Cancelled

ผลที่เคยส่งสำเร็จแต่ถูก Admin ยกเลิกเพื่ออนุญาตให้ทำใหม่ เก็บไว้ตรวจสอบย้อนหลัง ไม่ถือเป็นผลปัจจุบัน และไม่รวมในสถิติ dashboard

## หน้าสรุปผลรวม

หน้าที่แสดงผลของแบบประเมินแต่ละชุดแยกจากกัน หลังผู้ใช้ทำครบทั้ง 5 ชุดแล้ว รูปแบบคำแนะนำและรายละเอียดที่แสดงยังรอตัดสินใจ

## พนักงาน

ผู้ทำแบบประเมินที่ผ่าน SSO สามารถดูผลของตนเองได้หลังทำครบทั้ง 5 ชุดและส่งรอบการประเมินแล้ว

## Admin/HR

ผู้ใช้สิทธิ์พิเศษที่เข้าถึงหน้าเว็บผู้ดูแลผ่านบัญชี OneID และได้รับสิทธิ์ Admin ในระบบ ดูตารางคะแนนและระดับผลรายบุคคลของพนักงานทุกคน (พร้อม Masking ชื่อและรหัสพนักงาน) รวมถึง dashboard สถิติรวม แต่ไม่เห็นคำตอบรายข้อ

## Employee Assessment Web

เว็บสำหรับพนักงานทุกคน รวมถึงบุคลากร HR ในฐานะพนักงาน ใช้ทำแบบประเมินและดูผลของตนเองผ่าน OnePlatform SSO

## Admin Web

เว็บแยกสำหรับผู้ได้รับสิทธิ์ Admin ใช้ดูผลรายบุคคล dashboard จัดการคืนสิทธิ์ และส่งออกข้อมูล Excel

## ผู้เข้าเกณฑ์

พนักงานที่ผลประเมินถึงระดับที่ระบบกำหนดว่าต้องนับใน dashboard (เข้าเกณฑ์อย่างน้อยหนึ่งด้าน)

## PII Encryption (การเข้ารหัสข้อมูลส่วนบุคคล)

มาตรการรักษาความปลอดภัยข้อมูลในระบบ โดยทำการเข้ารหัส (Encrypt) ฟิลด์ข้อมูลส่วนบุคคลของพนักงาน ได้แก่ ชื่อ–นามสกุล, เพศ, อายุ, และรหัสพนักงาน ขณะจัดเก็บ (Encryption at rest)

## UI Masking (การพรางข้อมูลบนหน้าจอ)

การแสดงผลพรางข้อมูลส่วนบุคคลบนหน้าจอรายงานสำหรับ Admin เพื่อป้องกันการเปิดเผยตัวตนโดยไม่จำเป็น เช่น “นายสมชาย ทำงานดี” >> “นายสมXXXX ทำXXXX” และ INET9988776655 >> INET99XXXXXX55

## Admin Export (การส่งออกข้อมูล)

การส่งออกข้อมูลตารางผลประเมินตามตัวกรองเป็นไฟล์ Excel เท่านั้น โดยไม่มีคำตอบรายข้อ และต้องมีการยืนยันรหัสผ่านของผู้ใช้งานซ้ำก่อนดำเนินการ พร้อมบันทึก Audit Log ทุกครั้ง

## Data Retention & Audit Trail (นโยบายอายุข้อมูลและบันทึกการใช้งาน)

การเก็บรักษาข้อมูลผลประเมินที่ระบุตัวตนได้เป็นเวลา 1 ปีนับจากวันส่ง ก่อนดำเนินการ Anonymize และจัดเก็บ Audit Log อย่างปลอดภัยเป็นเวลา 2 ปี ครอบคลุมการเข้าสู่ระบบ การดู/ส่งออกข้อมูล การคืนสิทธิ์ และทุก Event ของ Admin
