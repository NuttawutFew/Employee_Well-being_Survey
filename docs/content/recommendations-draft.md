# ร่างคำแนะนำตามผลประเมิน

> สถานะ: โครงร่างสำหรับจัดทำเนื้อหา — ห้ามนำขึ้น production จนกว่าผู้เชี่ยวชาญด้านสุขภาพจิตจะตรวจและอนุมัติ

## โครงสร้างข้อความต่อหนึ่งระดับผล

1. ชื่อแบบประเมินและระดับผล
2. ความหมายโดยย่อด้วยภาษาที่ไม่ตีตรา
3. สิ่งที่ผู้ใช้ทำได้ด้วยตนเอง
4. เมื่อใดควรปรึกษาผู้เชี่ยวชาญ
5. ช่องทางขอความช่วยเหลือ (ยังไม่แสดงในเวอร์ชันแรกตามข้อกำหนดปัจจุบัน)
6. ข้อความว่าเป็นการคัดกรอง ไม่ใช่การวินิจฉัย
7. แหล่งอ้างอิง เวอร์ชัน วันที่มีผล และผู้อนุมัติ

## ชุดเนื้อหาที่ต้องจัดทำ

### ภาวะหมดไฟในการทำงาน

- ความอ่อนล้าทางอารมณ์: ต่ำ / ปานกลาง / สูง
- การลดความเป็นบุคคล: ต่ำ / ปานกลาง / สูง
- ความสำเร็จส่วนบุคคล: ต่ำ / ปานกลาง / สูง
- คำอธิบายภาพรวมที่ไม่รวมสามมิติเป็นคะแนนเดียว

### ความเครียด 20 ข้อ

- 0–5 คะแนน
- 6–17 คะแนน
- 18–25 คะแนน
- 26–29 คะแนน
- 30–60 คะแนน

### พลังสุขภาพจิต RQ

- ความทนต่อแรงกดดัน: ต่ำกว่าเกณฑ์ / เกณฑ์ปกติ / สูงกว่าเกณฑ์
- ความหวังและกำลังใจ: ต่ำกว่าเกณฑ์ / เกณฑ์ปกติ / สูงกว่าเกณฑ์
- การต่อสู้เอาชนะอุปสรรค: ต่ำกว่าเกณฑ์ / เกณฑ์ปกติ / สูงกว่าเกณฑ์
- คะแนนรวม: ต่ำกว่าเกณฑ์ / เกณฑ์ปกติ / สูงกว่าเกณฑ์

### โรคซึมเศร้า 9Q

- น้อยมาก
- น้อย
- ปานกลาง
- รุนแรง
- ข้อ 9 เป็นส่วนหนึ่งของคะแนนรวม 9Q และไม่ใช้สร้างสถานะความเสี่ยงฆ่าตัวตายของระบบ

### ความเสี่ยงซึมเศร้าและฆ่าตัวตาย 2Q Plus

- ไม่พบสัญญาณตามคำตอบ
- พบความเสี่ยงซึมเศร้า
- พบความเสี่ยงฆ่าตัวตาย
- พบทั้งสองความเสี่ยง

## ประเด็นรอการยืนยันก่อนเขียนข้อความฉบับเต็ม

- เกณฑ์เริ่มนับว่า “ผิดจากเกณฑ์ปกติ” ของแต่ละแบบ
- การทบทวนก่อน production ว่าต้องเพิ่มช่องทางช่วยเหลือและหมายเลขติดต่อหรือไม่
- ผู้เชี่ยวชาญหรือหน่วยงานผู้อนุมัติเนื้อหา
- ข้อความยินยอมและคำประกาศความเป็นส่วนตัว
- หลักการคิดคะแนน Burnout ที่ต้องตรวจทานกับผู้เชี่ยวชาญ
