# ADR-0005: การเข้าถึงผลประเมินตามบทบาท

- สถานะ: ยอมรับบางส่วน — รอกำหนดวิธีมอบสิทธิ์ Admin
- วันที่: 2026-09-02

## บริบท

ผลประเมินสุขภาพใจเป็นข้อมูลอ่อนไหว ต้องกำหนดว่าเจ้าของข้อมูลและผู้ดูแลระบบสามารถเห็นข้อมูลใดได้บ้าง

## การตัดสินใจ

ระบบมีอย่างน้อยสองบทบาท:

1. **พนักงาน** — ดูผลของตนเองได้หลังทำแบบประเมินครบทั้ง 5 ชุดและส่งรอบการประเมินแล้ว
2. **Admin/HR** — ใช้หน้าเว็บสำหรับผู้ดูแลที่แยกจากหน้าพนักงาน และสามารถดูผลของพนักงานทุกคนที่ส่งแบบประเมินแล้ว

Admin/HR เห็นข้อมูลสองระดับ:

- **ตารางผลรายบุคคล** — วันที่ ข้อมูลพนักงาน คะแนนรวม และระดับผลของแบบประเมินแต่ละชุด พร้อมการค้นหาและแบ่งหน้า
- **ภาพรวมองค์กร** — จำนวนผู้ทำแบบประเมิน จำนวนผู้เข้าเกณฑ์อย่างน้อยหนึ่งด้าน และจำนวน/ร้อยละของผู้เข้าเกณฑ์ในแต่ละด้าน

ไม่แสดงคำตอบรายข้อในหน้า Admin ตามตัวอย่างที่ได้รับ

## ผลตามมา

- ทุก endpoint ที่อ่านผลต้องตรวจสิทธิ์ฝั่ง server ไม่พึ่งการซ่อนเมนูฝั่งหน้าเว็บ
- พนักงานต้องไม่สามารถเปลี่ยนรหัสใน URL หรือ request เพื่ออ่านผลของผู้อื่นได้
- หน้า Admin ต้องมี audit log สำหรับการเปิดดูข้อมูลรายบุคคล
- ต้องกำหนดวิธีมอบ ถอน และทบทวนสิทธิ์ Admin
- ต้องมีข้อความแจ้งพนักงานก่อนเริ่มทำแบบประเมินว่า HR สามารถเข้าถึงผลที่ผูกกับตัวตนได้
- เกณฑ์ที่ใช้คำนวณสถิติ “เข้าเกณฑ์” ของแต่ละด้านต้องระบุอย่างชัดเจนและทดสอบแยกกัน
- ร้อยละต้องระบุ denominator ว่าคิดจากผู้ส่งแบบประเมินครบในขอบเขตตัวกรองใด
