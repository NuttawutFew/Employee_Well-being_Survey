# ADR-0026: แสดงคำถามเป็นกลุ่มละประมาณ 5 ข้อต่อหน้า

- สถานะ: ถูกแทนที่โดย ADR-0027
- วันที่: 2026-09-02

## บริบท

ระบบมีคำถามรวม 74 ข้อ การแสดงทีละข้อทำให้เปลี่ยนหน้าจำนวนมาก ขณะที่การแสดงทั้งแบบประเมินในหน้าเดียวทำให้หน้าบนมือถือยาวและตรวจข้อที่ยังไม่ตอบยาก

## การตัดสินใจ

เดิมเลือก layout แบบ C: แสดงคำถามครั้งละประมาณ 5 ข้อต่อหน้า แต่ภายหลังยืนยันว่าต้องการหนึ่งหน้าต่อหนึ่งแบบประเมิน จึงแทนที่ด้วย ADR-0027

หน้าสุดท้ายของแต่ละแบบอาจมีน้อยกว่า 5 ข้อ และแบบ 9Q/2Q Plusยังคงแบ่งตามขนาดที่เหมาะสมโดยไม่สร้างหน้าว่าง

## ผลตามมา

- ก่อนเปลี่ยนหน้า ผู้ใช้ต้องตอบทุกข้อที่แสดง หรือได้รับ error ที่ชี้ตำแหน่งข้อที่ยังไม่ตอบอย่างเข้าถึงได้
- การกด “บันทึกและถัดไป” บันทึกทุกคำตอบในกลุ่มแบบ atomic
- autosave รายคำตอบยังทำงานได้ แต่ปุ่มถัดไปเป็น checkpoint ที่ชัดเจน
- ความคืบหน้าแสดงทั้งชื่อแบบประเมิน ช่วงข้อปัจจุบัน และความคืบหน้ารวมโดยไม่เปิดเผยผลคะแนนก่อนส่ง
- ปุ่มย้อนกลับโหลดคำตอบ Draft เดิมและแก้ไขได้ตาม ADR-0008
