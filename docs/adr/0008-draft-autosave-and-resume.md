# ADR-0008: บันทึก Draft อัตโนมัติและกลับมาทำต่อได้

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-09-02

## บริบท

แบบประเมินรวมมีหลายข้อและอาจใช้เวลานาน ผู้ใช้อาจปิดหน้าเว็บ หมด session หรือเครือข่ายขาดหายก่อนส่งครบ

## การตัดสินใจ

ระบบบันทึกคำตอบ Draft อัตโนมัติ และเมื่อพนักงานเข้าสู่ระบบอีกครั้งจะกลับมาทำต่อจากแบบประเมินและข้อที่ยังไม่เสร็จ

ตราบใดที่รอบยังเป็น Draft พนักงานสามารถย้อนกลับไปยังแบบประเมินก่อนหน้าและแก้ไขคำตอบได้ทั้งหมด เมื่อส่งสำเร็จแล้วคำตอบและคะแนนถูกล็อก

## ผลตามมา

- Draft ต้องผูกกับรหัสพนักงานจาก OnePlatform ไม่ผูกกับ browser เพียงอย่างเดียว
- แต่ละคำตอบควรบันทึกแบบ atomic และรองรับการส่ง request ซ้ำโดยไม่สร้างข้อมูลซ้ำ
- UI ต้องแสดงสถานะกำลังบันทึก บันทึกแล้ว และบันทึกไม่สำเร็จอย่างเข้าใจง่าย
- หากบันทึกไม่สำเร็จ ต้องไม่พาผู้ใช้ไปต่อโดยทำให้เข้าใจผิดว่าคำตอบถูกเก็บแล้ว
- เมื่อ session หมดอายุ หลังเข้าสู่ระบบใหม่ต้องโหลด Draft เดิมได้
- ผู้ใช้ยังสามารถเลือกล้าง Draft ทั้งหมดและเริ่มใหม่ได้ตาม ADR-0007
- การแก้คำตอบต้องคำนวณความคืบหน้าใหม่ แต่ยังไม่สร้างหรือเปิดเผยผลสรุปก่อน Submitted
