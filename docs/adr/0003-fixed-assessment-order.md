# ADR-0003: แบบประเมินดำเนินตามลำดับตายตัว

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-09-02

## บริบท

ระบบต้องกำหนดว่าผู้ใช้สามารถเลือกทำแบบประเมินแต่ละชุดได้อย่างอิสระ หรือจำเป็นต้องทำตามลำดับที่ระบบกำหนด

## การตัดสินใจ

แบบประเมินทั้ง 5 ชุดมีลำดับตายตัว ผู้ใช้ไม่สามารถเลือกข้ามไปทำชุดอื่นก่อนลำดับได้

ลำดับคือ:

1. ภาวะหมดไฟในการทำงาน (Burnout)
2. ความเครียด (Stress Test)
3. พลังสุขภาพจิต (Resilience/RQ)
4. ความเสี่ยงโรคซึมเศร้า (9Q)
5. ความเสี่ยงซึมเศร้าและฆ่าตัวตาย (2Q Plus)

## ผลตามมา

- ระบบต้องบันทึกว่าในรอบปัจจุบันผู้ใช้อยู่ที่แบบประเมินและข้อใด
- เมื่อจบหนึ่งชุด ระบบนำผู้ใช้เข้าสู่ชุดถัดไปตามลำดับที่กำหนด
- ต้องกำหนดว่าสามารถย้อนกลับไปแก้คำตอบก่อนหน้าได้หรือไม่
