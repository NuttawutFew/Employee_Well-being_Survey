# ADR-0021: รองรับหลายขนาดหน้าจอสำหรับเว็บทั้งสองส่วน

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-09-02

## บริบท

พนักงานอาจทำแบบประเมินจากมือถือ แท็บเล็ต หรือคอมพิวเตอร์ ขณะที่ Admin ใช้งานตารางและ dashboard บนจอคอมพิวเตอร์เป็นหลัก แต่ยังต้องเข้าถึงจากอุปกรณ์อื่นได้

## การตัดสินใจ

- Employee Assessment Web รองรับมือถือ แท็บเล็ต และ PC อย่างเต็มรูปแบบ โดยออกแบบ mobile-first
- Admin Web ออกแบบ desktop-first และ responsive สำหรับแท็บเล็ตและมือถือ

## ผลตามมา

- แบบประเมินต้องไม่ใช้ interaction ที่พึ่ง hover และพื้นที่กดต้องเหมาะกับหน้าจอสัมผัส
- ความคืบหน้า ปุ่มย้อนกลับ/ถัดไป สถานะบันทึก และตัวเลือกคำตอบต้องใช้งานได้ทุก breakpoint
- ตาราง Admin บนจอแคบต้องใช้คอลัมน์สำคัญร่วมกับ expandable row/card หรือ horizontal scroll ที่มีหัวตารางคงที่ ไม่ย่อข้อความจนอ่านไม่ได้
- filter และ export ต้องใช้งานได้ด้วย touch และ keyboard
- ต้องทดสอบ responsive อย่างน้อยในขนาดมือถือ แท็บเล็ต โน้ตบุ๊ก และจอ desktop
