# ADR-0010: ซ่อนสถิติของกลุ่มขนาดเล็ก

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-09-02

## บริบท

การกรอง dashboard ตามบริษัท แผนก ตำแหน่ง พื้นที่ หรือคุณลักษณะอื่นอาจทำให้เหลือคนจำนวนน้อย จนสามารถอนุมานผลสุขภาพใจของบุคคลได้จากสถิติรวม

## การตัดสินใจ

เมื่อขอบเขตข้อมูลหลังใช้ตัวกรองมีพนักงานน้อยกว่า 5 คน ระบบไม่แสดงจำนวน ร้อยละ หรือกราฟสถิติรวม และแสดงข้อความว่า “ข้อมูลไม่เพียงพอสำหรับแสดงสถิติ”

กฎนี้ไม่เปลี่ยนสิทธิ์ของ Admin ในการค้นหาและเปิดข้อมูลรายบุคคลตาม ADR-0005

## ผลตามมา

- ฝั่ง server ต้องเป็นผู้ตรวจจำนวนกลุ่มและระงับค่าสถิติ ไม่ส่งค่าจริงมาให้ client แล้วค่อยซ่อน
- การ export และ API รายงานต้องใช้กฎเดียวกับ dashboard
- ต้องทดสอบการใช้ตัวกรองร่วมกันเพื่อไม่ให้อนุมานค่าที่ถูกซ่อนจากผลต่างระหว่างกลุ่มได้ง่าย
- ค่า threshold 5 ควรเป็นค่ากำหนดส่วนกลาง ไม่กระจายในหลายจุดของระบบ
