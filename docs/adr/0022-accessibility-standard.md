# ADR-0022: ใช้ WCAG 2.1 ระดับ AA เป็นเกณฑ์รับมอบ

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-09-02

## บริบท

แบบประเมินต้องใช้งานได้กับพนักงานที่มีความสามารถ อุปกรณ์ และวิธีเข้าถึงที่หลากหลาย โดยเฉพาะเนื้อหาสุขภาพที่ไม่ควรสร้างอุปสรรคเพิ่มเติม

## การตัดสินใจ

Employee Assessment Web และ Admin Web ต้องผ่าน WCAG 2.1 ระดับ AA

## ผลตามมา

- ทุก flow หลักต้องใช้งานด้วย keyboard ได้และมี focus indicator ชัดเจน
- คอนโทรลต้องมี accessible name, label, error association และสถานะที่ screen reader รับรู้ได้
- สีต้องผ่านเกณฑ์ contrast และไม่เป็นวิธีเดียวในการสื่อระดับผลหรือข้อผิดพลาด
- รองรับการขยายข้อความอย่างน้อย 200% โดยข้อมูลและการทำงานไม่สูญหาย
- touch target ต้องมีขนาดเหมาะสมและไม่วางชิดจนกดผิดง่าย
- autosave และ error message ต้องประกาศอย่างเหมาะสมโดยไม่รบกวนการตอบคำถาม
- การรับมอบต้องมีทั้ง automated accessibility tests และ manual keyboard/screen-reader checks
