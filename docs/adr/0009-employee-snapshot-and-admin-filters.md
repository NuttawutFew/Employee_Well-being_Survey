# ADR-0009: เก็บ snapshot ข้อมูลพนักงานและรองรับตัวกรอง Admin

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-09-02

## บริบท

ข้อมูลพนักงาน เช่น อายุ ตำแหน่ง แผนก หรือบริษัท สามารถเปลี่ยนภายหลังการประเมิน หากรายงานอ้างอิงข้อมูลล่าสุด ตัวเลขย้อนหลังอาจเปลี่ยนโดยไม่ได้มีการประเมินใหม่

## การตัดสินใจ

เมื่อพนักงานส่งแบบประเมิน ระบบเก็บ snapshot ของข้อมูลพนักงานจาก OnePlatform ณ เวลานั้นและใช้ snapshot คู่กับผลประเมินในหน้า Admin และ dashboard

หน้า Admin ต้องรองรับตัวกรองดังนี้:

- ช่วงวันที่ส่ง
- บริษัท
- แผนก
- ตำแหน่ง
- เพศ
- ช่วงอายุ
- พื้นที่ปฏิบัติงาน
- อายุงานเป็นช่วง: น้อยกว่า 1 ปี, 1–3 ปี, 3–5 ปี และมากกว่า 5 ปี
- กลุ่มที่เข้าเกณฑ์อย่างน้อยหนึ่งด้าน
- แบบประเมินและระดับผล
- สถานะ Submitted หรือ Cancelled

รองรับการค้นหารายบุคคลด้วยรหัสพนักงานหรือชื่อ–นามสกุล แยกจากตัวกรองเชิงสถิติ

## ผลตามมา

- เพิ่มบริษัท พื้นที่ปฏิบัติงาน และข้อมูลที่ใช้คำนวณอายุงานในข้อมูลที่ดึงจาก OnePlatform
- ผลและสถิติย้อนหลังไม่เปลี่ยนเมื่อโปรไฟล์ต้นทางเปลี่ยน
- ทุกตัวกรองใช้กับทั้งตารางรายบุคคลและ dashboard เพื่อให้ numerator และ denominator อยู่ในขอบเขตเดียวกัน
- UI ต้องแสดงตัวกรองที่กำลังใช้อยู่และมีคำสั่งล้างตัวกรอง
- ช่วงอายุต้องคำนวณจากอายุใน snapshot หรือวันเกิด ณ วันที่ส่ง ไม่คำนวณใหม่ตามวันปัจจุบัน
- ตัวกรองแบบตัวเลือกควรรองรับหลายค่าในมิติเดียวกันและใช้เงื่อนไข OR ภายในมิติ แต่ใช้ AND ข้ามมิติ
