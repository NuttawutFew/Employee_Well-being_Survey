# ADR-0027: หนึ่งหน้าต่อหนึ่งแบบประเมิน

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-09-02

## บริบท

ระบบมีแบบประเมิน 5 ชุดตามลำดับตายตัว ผู้ใช้ต้องการให้จำนวนหน้าหลักสอดคล้องกับจำนวนแบบประเมิน ไม่แบ่งแบบหนึ่งออกเป็นหลายหน้า

## การตัดสินใจ

หน้าคำถามมีทั้งหมด 5 หน้า:

1. Burnout — 22 ข้อ
2. Stress — 20 ข้อ
3. Resilience/RQ — 20 ข้อ
4. Depression/9Q — 9 ข้อ
5. Suicide Risk/2Q Plus — 3 ข้อ

แต่ละหน้าแสดงคำถามทั้งหมดของแบบประเมินนั้นและมีปุ่มบันทึกเพื่อไปยังแบบถัดไป

## ผลตามมา

- หน้าของ Burnout, Stress และ RQ จะยาวบนมือถือ จึงต้องมีเลขข้อชัดเจน แถบ/หัวข้อบอกแบบปัจจุบัน และประสิทธิภาพการ render ที่ดี
- autosave ทำงานรายคำตอบตาม ADR-0008 ไม่รอให้ผู้ใช้กดปุ่มท้ายหน้า
- เมื่อกดไปแบบถัดไป ต้องตรวจว่าตอบครบทุกข้อและพา focus/scroll ไปยังข้อแรกที่ยังไม่ตอบ
- ทุกคำถามเป็น required และต้องแสดง error ใกล้คำถาม รวมถึงประกาศ error summary สำหรับ screen reader โดยไม่ล้างคำตอบที่กรอกแล้ว
- ผู้ใช้ย้อนกลับไปแก้คำตอบของหน้าแบบประเมินก่อนหน้าได้ตราบใดที่ยังเป็น Draft
- หน้า 5 ต้องมีขั้นตอนยืนยันก่อนส่งผลทั้งหมด เพื่อไม่ให้การกดโดยไม่ตั้งใจเปลี่ยน Draft เป็น Submitted
