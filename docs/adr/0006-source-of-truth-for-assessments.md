# ADR-0006: ใช้เอกสารแบบประเมินต้นฉบับเป็นแหล่งข้อมูลหลัก

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-09-02

## บริบท

ภาพตัวอย่างหน้า Admin ใช้ชื่อ “ภาวะเครียด (ST-5)” แต่ไฟล์ `stress-assessment.pdf` เป็นแบบประเมินความเครียด 20 ข้อ คะแนนเต็ม 60 จึงเกิดความขัดแย้งระหว่างตัวอย่างหน้าจอกับเอกสารแบบประเมิน

## การตัดสินใจ

ภาพหน้าเว็บเป็นเพียงตัวอย่าง UX/UI ส่วนคำถาม ตัวเลือก คะแนน เกณฑ์ และชื่อแบบประเมินจริงให้อ้างอิงไฟล์ต้นฉบับทั้ง 5 ชุดใน workspace

## ผลตามมา

- ระบบใช้แบบประเมินความเครียด 20 ข้อตาม `stress-assessment.pdf` ไม่ใช้ ST-5 จากภาพตัวอย่าง
- ป้ายกำกับ คอลัมน์ และการ์ด dashboard ต้องปรับให้ตรงกับแบบประเมินจริง
- ควรแปลงนิยามแบบประเมินเป็นข้อมูล versioned และมีชุดทดสอบสูตรคะแนน เพื่อป้องกัน UI หรือโค้ดเปลี่ยนความหมายทางคลินิกโดยไม่ตั้งใจ
