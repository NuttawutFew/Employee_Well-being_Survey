# ADR-0007: พนักงานส่งแบบประเมินได้เพียงครั้งเดียว

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-09-02

## บริบท

ต้องกำหนดว่าพนักงานสามารถทำแบบประเมินซ้ำเพื่อดูแนวโน้มตามเวลาได้หรือไม่

## การตัดสินใจ

รหัสพนักงานหนึ่งรหัสส่งรอบการประเมินครบทั้ง 5 ชุดได้เพียงครั้งเดียวตลอดอายุระบบ ไม่รีเซ็ตตามปีหรือ Campaign

ก่อนส่งสำเร็จ รอบการประเมินมีสถานะ **Draft** พนักงานสามารถล้างคำตอบทั้งหมดและเริ่มทำใหม่ตั้งแต่แบบประเมินแรกได้

หลังส่งสำเร็จ Admin มีสิทธิ์รีเซ็ตเพื่อให้พนักงานทำแบบประเมินใหม่ได้ ในภาวะปกติพนักงานยังคงส่งได้เพียงครั้งเดียว

เมื่อ Admin รีเซ็ต ระบบเก็บผลเดิมเป็นประวัติในสถานะ **Cancelled** และไม่นำผลนั้นไปคำนวณ dashboard จากนั้นจึงเปิดให้พนักงานสร้าง Draft รอบใหม่

## ผลตามมา

- ต้องบังคับ uniqueness ของการส่งสำเร็จต่อรหัสพนักงานที่ฐานข้อมูลหรือ transaction ฝั่ง server
- หลังส่งสำเร็จ พนักงานเข้าระบบมาเพื่อดูผลเดิม แต่เริ่มรอบใหม่ไม่ได้
- การล้าง Draft ต้องลบคำตอบที่บันทึกไว้ทั้งหมดของรอบนั้น แต่ไม่กระทบข้อมูลบัญชีพนักงาน
- คำขอส่งซ้ำจากหลายแท็บหรือการกดซ้ำต้องคืนผลเดิมอย่างปลอดภัย ไม่สร้างระเบียนซ้ำ
- การรีเซ็ตหลังส่งต้องตรวจสิทธิ์ฝั่ง server และบันทึก Admin ผู้ดำเนินการ เวลา และเหตุผล
- ห้ามแก้ไขคะแนนหรือคำตอบของผลเดิม ให้เปลี่ยนเฉพาะสถานะเป็น Cancelled พร้อมความสัมพันธ์ไปยังรอบใหม่
- dashboard และรายการผลปัจจุบันนับเฉพาะรอบ Submitted ล่าสุดที่ยังไม่ถูกยกเลิก
- ระบบไม่ต้องมีกราฟแนวโน้มผลส่วนบุคคลหลายช่วงเวลา
- ระบบไม่ต้องมีโมเดล Campaign หรือรอบประเมินประจำปี การทำใหม่เกิดจาก Admin Reset เท่านั้น
