# ADR-0012: เนื้อหาและโครงสร้างหน้าสรุปผลพนักงาน

- สถานะ: ยอมรับบางส่วน — รอกฎสถานะภาพรวมและการอนุมัติเนื้อหา
- วันที่: 2026-09-02

## บริบท

หลังส่งแบบประเมินครบทั้ง 5 ชุด พนักงานต้องได้รับผลที่เข้าใจง่ายบนโทรศัพท์ โดยไม่ทำให้เข้าใจว่าเป็นการวินิจฉัยทางการแพทย์

## การตัดสินใจ

หน้าสรุปผลเป็น mobile-first และมีองค์ประกอบดังนี้:

- สถานะภาพรวมของสุขภาพใจ
- ข้อความชัดเจนว่าเป็นการคัดกรองเบื้องต้น ไม่ใช่การวินิจฉัยทางการแพทย์
- การ์ดแยกสำหรับแบบประเมินทั้ง 5 ชุด
- แต่ละการ์ดแสดงชื่อแบบประเมิน คะแนน ระดับผล และคำอธิบาย
- แต่ละการ์ดมีคำแนะนำในการดูแลตนเองหรือการติดต่อผู้เชี่ยวชาญ
- เมื่อมีความเสี่ยง ให้แสดงสถานะความเสี่ยงอย่างเด่นชัด

ภาพตัวอย่างใช้เป็นแนวทางด้าน UX/UI เท่านั้น ค่าคะแนน ชื่อระดับ และความหมายต้องอ้างอิงเอกสารต้นฉบับตาม ADR-0006

## ผลตามมา

- ห้ามรวมคะแนนจากต่างแบบประเมินเป็นคะแนนเดียว
- สถานะภาพรวมต้องได้จากกฎที่อธิบายและทดสอบได้ ไม่ใช้โมเดลคาดการณ์
- สีไม่ควรเป็นวิธีเดียวในการสื่อระดับ ต้องมีข้อความและสัญลักษณ์ประกอบ
- คำแนะนำด้านสุขภาพต้องมีเจ้าของเนื้อหา แหล่งอ้างอิง และ version เพื่อให้ตรวจสอบย้อนหลังได้
- ในเวอร์ชันนี้ยังไม่แสดงเบอร์หรือช่องทางติดต่อเมื่อพบความเสี่ยงฆ่าตัวตาย โดยต้องให้ผู้เชี่ยวชาญและเจ้าของระบบทบทวนความเสี่ยงของการตัดสินใจนี้ก่อน production
- แบบ 2Q Plus เป็นผลแบบพบ/ไม่พบความเสี่ยง ไม่รองรับการเติมระดับต่ำ ปานกลาง หรือสูงหากไม่มีเกณฑ์อื่น
- ข้อความผลบวกด้านการฆ่าตัวตายใช้คำว่า **“พบความเสี่ยงฆ่าตัวตาย”** ไม่ใช้คำว่า “มีความเสี่ยงสูง”

## การจัดทำคำแนะนำ

ทีมพัฒนาจะจัดทำร่างคำแนะนำแยกตามแบบประเมินและระดับผล โดยอ้างอิงเกณฑ์ในเอกสารต้นฉบับและแหล่งข้อมูลทางการ จากนั้นต้องส่งให้ผู้เชี่ยวชาญด้านสุขภาพจิตตรวจและอนุมัติก่อนเผยแพร่จริง

เนื้อหาแต่ละรายการต้องเก็บ metadata อย่างน้อย ได้แก่ แบบประเมิน ระดับผล ข้อความ แหล่งอ้างอิง เวอร์ชัน วันที่มีผล และผู้อนุมัติ
