# ADR-0001: ระบบให้ผู้ใช้ประเมินสุขภาพใจด้วยตนเอง

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-09-02

## บริบท

ระบบประกอบด้วยแบบประเมินสุขภาพใจ 5 ชุด รวมถึงคำถามที่สามารถบ่งชี้ความเสี่ยงต่อการฆ่าตัวตาย จึงต้องกำหนดบทบาทของระบบและผู้รับผิดชอบต่อผลลัพธ์ให้ชัดเจนก่อนออกแบบขั้นตอนใช้งาน

## การตัดสินใจ

ระบบเป็นเครื่องมือประเมินด้วยตนเอง ผู้ใช้งานเป็นผู้ตอบและอ่านผลด้วยตนเอง ไม่มีบุคลากรทางการแพทย์หรือเจ้าหน้าที่ขององค์กรเฝ้าระวังผลแบบเรียลไทม์

## ผลตามมา

- ทุกหน้าผลลัพธ์ต้องสื่อว่าเป็นการคัดกรอง ไม่ใช่การวินิจฉัย
- ระบบต้องไม่สร้างความคาดหวังว่าจะมีเจ้าหน้าที่ติดต่อกลับ
- เมื่อพบความเสี่ยงเร่งด่วน ระบบต้องแสดงทางเลือกขอความช่วยเหลือที่ชัดเจนและทำได้ทันที
- รูปแบบการแจ้งเตือน การเก็บข้อมูล และการเชื่อมต่อบริการช่วยเหลือยังต้องตัดสินใจเพิ่มเติม
