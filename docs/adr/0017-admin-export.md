# ADR-0017: Admin ส่งออกข้อมูลสรุปตามตัวกรอง

- สถานะ: ยอมรับแล้ว (ปรับปรุงรองรับ Excel & CSV และการควบคุมสิทธิ์ Export)
- วันที่: 2026-09-02 (อัปเดต 2026-09-08)

## บริบท

HR ต้องนำผลไปใช้งานต่อภายนอกหน้า Admin แต่ไฟล์ส่งออกเพิ่มความเสี่ยงต่อการกระจายข้อมูลสุขภาพใจที่ระบุตัวบุคคลได้ จึงจำเป็นต้องมีการควบคุมสิทธิ์การส่งออกข้อมูลอย่างเข้มงวด การจำกัดขอบเขตข้อมูล และการยืนยันตัวตนซ้ำก่อนนำข้อมูลออก

## การตัดสินใจ

1. **รูปแบบไฟล์ส่งออก**:
   Admin สามารถส่งออกข้อมูลเป็น **ไฟล์ Excel (.xlsx/.xls) หรือไฟล์ CSV (UTF-8 with BOM)** โดยใช้ขอบเขตตัวกรองปัจจุบัน และไม่รวมคำตอบรายข้อเด็ดขาด (Zero Raw Answers)

2. **การควบคุมสิทธิ์ (Permission Gating & Hide Export Button - Step 21)**:
   ผู้ดูแลระบบจะต้องได้รับสิทธิ์ `can_export` ซึ่งกำหนดโดย Super Admin (ตาม ADR-0032) หากผู้ใช้งานไม่มีสิทธิ์ดังกล่าว:
   - **บนหน้าจอ UI**: ปุ่มส่งออกข้อมูล (Export Button) จะถูก **ซ่อนโดยสมบูรณ์**
   - **บน API Endpoint**: ระบบจะทำการตรวจสอบสิทธิ์ และตอบกลับด้วย `403 Forbidden` หากตรวจพบการพยายามเรียกใช้โดยไม่ได้รับอนุญาต

3. **การยืนยันรหัสผ่าน ONE ID ซ้ำ (Steps 13 & 22)**:
   ก่อนเริ่มกระบวนการ Export ข้อมูล ระบบจะต้องแสดงหน้าต่างยืนยันให้ผู้ใช้งาน **ใส่รหัสผ่านของบัญชี ONE ID อีกครั้ง** เพื่อยืนยันตัวตนก่อนดำเนินการต่อ หากรหัสผ่านไม่ถูกต้อง ระบบจะแจ้งเตือนว่า *"รหัสผ่านไม่ถูกต้อง ไม่สามารถดาวน์โหลดเอกสารได้"* (Step 23) และจะต้องบันทึก Audit Log การนำข้อมูลออกทุกครั้ง

4. **เนื้อหาของไฟล์**:
   ไฟล์รายบุคคลประกอบด้วย employee snapshot (Masked PII ตามข้อกำหนดความปลอดภัย), คะแนนรวม, ระดับผล, และสถานะของแต่ละแบบประเมินตามข้อมูลที่ Admin เห็นบนตาราง

## ผลตามมา

- การ Export ข้อมูลรองรับทั้งไฟล์ Excel (.xls/.xlsx) และ CSV (UTF-8 with BOM รองรับภาษาไทยบน MS Excel ได้ทันที)
- เพิ่มความมั่นคงปลอดภัยสารสนเทศด้วยการซ่อนปุ่มส่งออกและ Gating สิทธิ์ระดับ Server
- มีขั้นตอนบังคับยืนยันรหัสผ่าน ONE ID ซ้ำก่อนอนุญาตให้ดาวน์โหลดไฟล์
- ทุกการ export ต้องตรวจสิทธิ์ฝั่ง server และมี audit log บันทึกผู้ใช้งาน วันเวลา ตัวกรอง รูปแบบไฟล์ (Excel/CSV) และจำนวนรายการที่นำข้อมูลออก
- กฎซ่อนสถิติกลุ่มน้อยกว่า 5 คนตาม ADR-0010 ใช้กับ export เชิงสถิติด้วย
- ไฟล์ต้องระบุเวลาที่สร้าง ตัวกรองที่ใช้ และคำเตือนว่าเป็นข้อมูลสุขภาพอ่อนไหว
- ชื่อไฟล์ต้องไม่ใส่ชื่อพนักงานหรือข้อมูลอ่อนไหวโดยไม่จำเป็น
- การสร้างไฟล์ควรทำแบบชั่วคราวและลบจากพื้นที่ server หลังดาวน์โหลดหรือหมดอายุ
- ไม่ส่งไฟล์ผ่านอีเมลอัตโนมัติในขอบเขตปัจจุบัน
