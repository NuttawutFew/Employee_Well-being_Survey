# ADR-0020: เปิดใช้ภาษาไทยก่อนและเตรียมโครงสร้างหลายภาษา

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-09-02

## บริบท

กลุ่มผู้ใช้เริ่มต้นใช้ภาษาไทย แต่ระบบอาจต้องเพิ่มภาษาอังกฤษในอนาคต เนื้อหาของแบบประเมินผูกกับ version และการตรวจรับรอง จึงไม่ควรฝังข้อความไว้กับสูตรคะแนนหรือโค้ดหน้าจอ

## การตัดสินใจ

เวอร์ชันแรกเปิดใช้งานภาษาไทยเพียงภาษาเดียว แต่โครงสร้างเนื้อหารองรับ locale ตั้งแต่ต้น

## ผลตามมา

- คำถาม ตัวเลือก คำชี้แจง ระดับผล คำอธิบาย และคำแนะนำเก็บแยกตาม locale และ assessment version
- สูตรคะแนนและรหัสคำตอบไม่ขึ้นกับภาษาที่แสดง
- ภาษาใหม่ต้องผ่านการแปลและตรวจความเทียบเท่าของเครื่องมือก่อนเปิดใช้ ไม่ใช่แปลด้วยเครื่องแล้วเผยแพร่ทันที
- UI ต้องรองรับข้อความที่ยาวขึ้นโดยไม่แตก แม้ยังเปิดเฉพาะภาษาไทย
