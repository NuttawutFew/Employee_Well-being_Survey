# ADR-0028: ยืนยันก่อนส่งแบบประเมินขั้นสุดท้าย

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-09-02

## บริบท

การส่งสำเร็จจะล็อกคำตอบและใช้สิทธิ์ทำแบบประเมินหนึ่งครั้ง จึงต้องป้องกันการส่งโดยไม่ตั้งใจ

## การตัดสินใจ

หลังตอบหน้า 2Q Plus ครบ ระบบแสดง confirmation dialog ว่า “เมื่อส่งแล้วจะไม่สามารถแก้ไขคำตอบได้” พร้อมสองคำสั่ง:

- “กลับไปตรวจสอบ” — ปิด dialog และคงสถานะ Draft
- “ยืนยันส่งแบบประเมิน” — ส่งคำตอบทั้งหมดและเปลี่ยนเป็น Submitted

## ผลตามมา

- ปุ่มยืนยันต้องถูก disable ระหว่างส่งและ request ต้องเป็น idempotent
- server ต้องตรวจความครบถ้วน version และ ownership ของ Draft อีกครั้งภายใน transaction
- หากส่งสำเร็จ ให้แสดงผลเดิมแม้ client retry จาก timeout
- หากส่งไม่สำเร็จ ต้องคง Draft และแจ้งให้ลองใหม่โดยไม่สร้างผลบางส่วน
- dialog ต้อง trap focus อย่างถูกต้อง รองรับ Escape และคืน focus ไปยังปุ่มเดิมเมื่อปิด
