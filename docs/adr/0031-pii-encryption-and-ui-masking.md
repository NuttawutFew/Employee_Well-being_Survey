# ADR-0031: การเข้ารหัสข้อมูลส่วนบุคคล (PII Encryption) และการพรางข้อมูลบนหน้าจอรายงาน (UI Masking)

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-09-07

## บริบท

ข้อมูลพนักงานที่ผูกกับผลการประเมินสุขภาพจิตจัดเป็นข้อมูลส่วนบุคคลที่มีความอ่อนไหวสูง (Sensitive Personal Data) เพื่อให้สอดคล้องกับ พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA) และมาตรฐานความมั่นคงปลอดภัยสารสนเทศขององค์กร จำเป็นต้องมีมาตรการป้องกันการเข้าถึงและการรั่วไหลของข้อมูลทั้งในระดับการจัดเก็บ (At Rest) และระดับการแสดงผลบนหน้าจอรายงานของผู้ดูแลระบบ (On Screen)

## การตัดสินใจ

1. **การเข้ารหัสข้อมูลส่วนบุคคลขณะจัดเก็บ (PII Encryption at Rest)**:
   ระบบทำการเข้ารหัสข้อมูลของพนักงานในฟิลด์สำคัญ 4 ฟิลด์ด้วยมาตรฐานการเข้ารหัสแบบสมมาตรระดับสูง (เช่น AES-256-GCM):
   - **ชื่อ–นามสกุล** (`full_name`)
   - **เพศ** (`gender`)
   - **อายุ** (`age`)
   - **รหัสพนักงาน** (`employee_id`)

2. **การพรางข้อมูลบนหน้าจอรายงาน (UI Masking)**:
   บนหน้าจอรายงานและตารางผลประเมินรายบุคคลสำหรับทีม HR/Admin ระบบจะต้องแสดงผลแบบพรางข้อมูล (Masking) ใน 2 ฟิลด์หลักเพื่อป้องกันการมองเห็นหรือการถ่ายภาพหน้าจอโดยไม่ตั้งใจ:
   - **ชื่อ–นามสกุล**: เช่น `“นายสมชาย ทำงานดี”` >> `“นายสมXXXX ทำXXXX”` (พรางตัวอักษรส่วนท้ายของชื่อและนามสกุล)
   - **รหัสพนักงาน**: เช่น `“INET9988776655”` >> `“INET99XXXXXX55”` (คงอักขระส่วนหน้าและส่วนท้ายไว้ พรางอักขระส่วนกลางด้วย `X`)

3. **ความสอดคล้องกับการค้นหาและการส่งออก**:
   - การค้นหา (Search) รายบุคคลด้วยรหัสพนักงานหรือชื่อ ระบบจะทำการค้นหาผ่าน Server-side Query ด้วยการแมปข้อมูลที่ปลอดภัย
   - การส่งออกข้อมูลเป็นไฟล์ Excel จะต้องผ่านการยืนยันรหัสผ่านบัญชีผู้ใช้ซ้ำ (Password Re-confirmation) และมีการบันทึก Audit Log ทุกครั้ง

## ผลตามมา

- ฐานข้อมูลจะจัดเก็บฟิลด์ PII ทั้ง 4 ฟิลด์ในรูปแบบ Encrypted Ciphertext พร้อม IV และ Tag
- Frontend Admin Web แสดงผลฟิลด์ชื่อและรหัสพนักงานในรูปแบบ Masked String เสมอ
- หากมีความจำเป็นต้องตรวจสอบตัวตนจริง ผู้ดูแลระบบต้องดำเนินการผ่านกระบวนการ Audit หรือการขอสิทธิ์ที่มีขั้นตอนตรวจสอบย้อนหลัง
- ป้องกันการเข้าถึงข้อมูลโดยมิชอบจากการดัมป์ฐานข้อมูลโดยตรง (Direct Database Dump)
- ป้องกันการเปิดเผยข้อมูลส่วนบุคคลต่อผู้ไม่มีส่วนเกี่ยวข้องที่อาจมองเห็นหน้าจอรายงาน
