# ADR-0029: ไม่ส่งการแจ้งเตือนความเสี่ยงแบบเรียลไทม์

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-09-02

## บริบท

ระบบเป็นการประเมินด้วยตนเองและไม่มีเจ้าหน้าที่เฝ้าระวังผลแบบเรียลไทม์ การส่งแจ้งเตือนอาจสร้างความคาดหวังว่าจะมีผู้รับผิดชอบตอบสนองทันที

## การตัดสินใจ

เมื่อข้อ 3 ของ 2Q Plus พบความเสี่ยงฆ่าตัวตาย ระบบไม่ส่งอีเมล SMS หรือ notification ไปยัง Admin/HR โดยอัตโนมัติ Admin เห็นสถานะเมื่อเข้าสู่ Admin Web และดูตาราง/dashboard เท่านั้น

## ผลตามมา

- คำชี้แจงและหน้าผลต้องไม่ระบุหรือสื่อว่าจะมีเจ้าหน้าที่ติดต่อกลับ
- Admin Web ต้องแสดงสถานะความเสี่ยงอย่างชัดเจนและรองรับตัวกรอง แต่ไม่อ้างว่าเป็นระบบ alerting
- ห้ามสร้าง background escalation workflow ในขอบเขตเวอร์ชันแรก
- การเปลี่ยนไปใช้ real-time notification ภายหลังต้องมีเจ้าของกระบวนการ response, SLA, ผู้รับผิดชอบ และการทบทวนด้านกฎหมาย/คลินิกก่อน
