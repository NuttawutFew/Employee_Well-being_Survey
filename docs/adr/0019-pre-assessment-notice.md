# ADR-0019: แสดงคำชี้แจงก่อนเริ่มแบบประเมิน

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-09-02

## บริบท

ผลประเมินผูกกับรหัสพนักงานและ Admin/HR สามารถดูข้อมูลรายบุคคลได้ พนักงานจึงต้องรับทราบขอบเขตการใช้ข้อมูลก่อนเริ่มตอบ

## การตัดสินใจ

หลังผ่าน OnePlatform และก่อนสร้าง Draft ระบบแสดงหน้าคำชี้แจงให้พนักงานรับทราบ

คำชี้แจงต้องครอบคลุมอย่างน้อย:

- วัตถุประสงค์ของการประเมิน
- แบบประเมินทั้ง 5 ชุดและระยะเวลาโดยประมาณ
- ข้อมูลพนักงานและคำตอบที่ระบบเก็บ
- การผูกผลกับตัวตน
- การที่ Admin/HR สามารถดูผลรายบุคคลและสถิติรวมได้
- ระยะเวลาเก็บ 3 ปีและการทำให้ไม่ระบุตัวตนหลังครบอายุ
- การ export ข้อมูลโดย Admin
- ข้อความว่าเป็นการคัดกรอง ไม่ใช่การวินิจฉัย
- ช่องทางติดต่อผู้ควบคุมข้อมูลหรือผู้ดูแลระบบ

ระบบเก็บ notice version เวลา และรหัสพนักงานที่กดยืนยันรับทราบ

หน้าดังกล่าวมีปุ่มหลัก **“รับทราบและเริ่มทำแบบประเมิน”** เมื่อกดแล้วระบบจึงสร้าง Draft และนำผู้ใช้เข้าสู่แบบ Burnout หากยังไม่กด ระบบจะไม่สร้าง Draft หรือบันทึกคำตอบ

## ผลตามมา

- เมื่อเนื้อหาสำคัญเปลี่ยน ต้องออก notice version ใหม่และกำหนดว่าผู้ใช้เดิมต้องรับทราบใหม่หรือไม่
- การยืนยันต้องเกิดก่อนบันทึกคำตอบข้อแรก
- คำว่า “รับทราบ” ไม่ควรถูกนำไปใช้แทนฐานกฎหมายหรือความยินยอมโดยอัตโนมัติ ต้องให้ฝ่ายกฎหมาย/PDPA ตรวจข้อความก่อน production
