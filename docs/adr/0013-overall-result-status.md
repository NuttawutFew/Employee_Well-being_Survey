# ADR-0013: สถานะภาพรวมใช้ผลที่รุนแรงที่สุด

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-09-02

## บริบท

หน้าสรุปต้องแสดงสถานะภาพรวมเหนือการ์ดรายแบบ โดยไม่รวมคะแนนต่างมาตรวัดเป็นคะแนนเดียว

## การตัดสินใจ

หากอย่างน้อยหนึ่งด้านผิดจากเกณฑ์ปกติ ระบบแสดงสถานะภาพรวมว่า “ควรได้รับการดูแลสุขภาพใจเพิ่มเติม”

ระบบเลือกน้ำหนักการสื่อสารจากผลที่มีความเร่งด่วนสูงสุด โดยความเสี่ยงฆ่าตัวตายมีลำดับสูงสุดและต้องแสดงช่องทางขอความช่วยเหลืออย่างเด่นชัด

ระบบยังคงแสดงผลรายแบบทั้ง 5 ชุดครบถ้วน และไม่คำนวณคะแนนสุขภาพใจรวม

เกณฑ์ “เข้าเกณฑ์อย่างน้อยหนึ่งด้าน” คือ:

- Burnout: มิติใดมิติหนึ่งอยู่ระดับปานกลางหรือสูง
- Stress: คะแนนรวมตั้งแต่ 18 คะแนนขึ้นไป
- RQ: มิติใดมิติหนึ่งต่ำกว่าเกณฑ์ปกติ
- 9Q: คะแนนรวมตั้งแต่ 7 คะแนนขึ้นไป โดยข้อ 9 คิดรวมเป็นส่วนหนึ่งของ 9Q เท่านั้น
- 2Q Plus: ตอบ “มี” อย่างน้อยหนึ่งข้อ

ผล 9Q และผลคัดกรองความเสี่ยงฆ่าตัวตายไม่ถูกรวมกัน ข้อ 9 ของ 9Q ไม่ใช้สร้างสถานะ “พบความเสี่ยงฆ่าตัวตาย” ของระบบ

## ผลตามมา

- ต้องนิยามเกณฑ์ “ผิดจากเกณฑ์ปกติ” แยกต่อแบบประเมินและ version
- กฎสถานะภาพรวมต้องเป็น deterministic rule ที่มี automated tests
- dashboard “เข้าเกณฑ์อย่างน้อยหนึ่งด้าน” ต้องใช้กฎชุดเดียวกับหน้าผลพนักงาน
- ต้องออกแบบกรณีพบหลายความเสี่ยงพร้อมกันโดยไม่ลดทอนคำแนะนำที่เร่งด่วนกว่า
